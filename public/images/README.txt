مجلد الصور العام (Public Images Folder)
=====================================

هذا المجلد مخصص لحفظ وتخزين الصور المستخدمة في الموقع (مثل شعار المنصة، صور المحلات والمنشآت، وصور الإعلانات البانر).

طريقة الاستخدام في لوحة التحكم:
------------------------------
عند إضافة أو تعديل منشأة أو إعلان، يمكنك كتابة المسار النسبي المباشر للصورة كالتالي:
/images/اسم_الصورة.jpg (أو .png / .svg / .webp)

أمثلة على صور متوفرة افتراضياً:
- /images/bahrain_bg.jpg (صورة خلفية البحرين)
- /images/logo_placeholder.png (صورة الشعار الافتراضي)

--------------------------------------------------------------------------------

Public Images Folder
====================

This folder is designated for storing all image assets used on the platform (such as the platform logo, business/store cover photos, and banner advertisements).

How to use in the Dashboard/Admin Panel:
----------------------------------------
When adding or editing a business or an advertisement, you can reference any image stored in this folder using its direct relative path:
/images/image_name.jpg (or .png / .svg / .webp)

Default available image examples:
- /images/bahrain_bg.jpg (Bahrain background pattern)
- /images/logo_placeholder.png (Default logo placeholder)
