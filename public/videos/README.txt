مجلد الفيديو العام (Public Videos Folder)
=====================================

هذا المجلد مخصص لحفظ وتخزين ملفات الفيديو المستخدمة للإعلانات والمقاطع الترويجية في الموقع.

طريقة الاستخدام في لوحة التحكم:
------------------------------
عند إضافة إعلان فيديو جديد، اختر نوع الوسائط (فيديو) واكتب مسار ملف الفيديو مباشرة كالتالي:
/videos/اسم_الفيديو.mp4 (أو أي صيغة مدعومة مثل ويب إم .webm)

أمثلة على فيديوهات متوفرة افتراضياً:
- /videos/bahrain_promo.mp4 (مقطع ترويجي للبحرين)

--------------------------------------------------------------------------------

Public Videos Folder
====================

This folder is designated for storing all video assets and promotional clips used on the platform.

How to use in the Dashboard/Admin Panel:
----------------------------------------
When adding a new video advertisement, set the media type to "Video" and input the direct relative path to the video file:
/videos/video_name.mp4 (or other supported formats like .webm)

Default available video examples:
- /videos/bahrain_promo.mp4 (Bahrain promotional clip)
