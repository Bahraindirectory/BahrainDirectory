
# دليل إضافة البيانات يدوياً (Bahrain Services Directory)

يمكنك تعديل البيانات الموجودة في الموقع من خلال طريقتين:

## 1. تعديل الكود (ملف constants.tsx)
ابحث عن الثابت `INITIAL_LISTINGS` في ملف `constants.tsx`. يمكنك إضافة كائنات جديدة تتبع الهيكل التالي:

```typescript
{
  id: '3',
  name: { ar: 'اسم المحل بالعربي', en: 'Shop Name English' },
  category: 'food', // اختر من: food, supermarket, health, cars, others
  subCategory: 'كرك', // يجب أن يتطابق مع أحد التصنيفات الفرعية في CATEGORIES
  area: { ar: 'المنامة', en: 'Manama' },
  block: '304', // المجمع السكني (رقم فقط)
  phone: ['+973 33333333'],
  googleMapsUrl: 'رابط الخرائط من جوجل',
  instagramUrl: 'رابط حساب الإنستغرام'
}
```

## 2. لوحة التحكم (Admin Panel)
يمكنك الوصول للوحة التحكم عبر أيقونة "Dashboard" في أعلى الصفحة.
- يمكنك حالياً إضافة منشآت جديدة وحذف المنشآت الحالية.
- يتم تخزين التغييرات في متصفحك (LocalStorage) لضمان بقائها عند تحديث الصفحة.

## 3. ربط البيانات لاحقاً
هذا التطبيق مصمم ليكون جاهزاً للربط مع Firebase أو Google Sheets API بسهولة من خلال استبدال `useState` في `App.tsx` بطلبات `fetch` من قاعدة البيانات الخاصة بك.
